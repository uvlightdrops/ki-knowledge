# Daily Timeline

## Purpose

Summarize temporal patterns from cached source data into daily activity or trending snapshots. The view is not limited to Jira: any timestamped source that is imported and cached can be grouped by day and analyzed for themes or progress.

## Features

- aggregate entries by day
- extract dominant topics or summaries per period
- support trend monitoring and narrative reconstruction
- work with cached structured or semi-structured data

## Example

```bash
python examples/jira_daily_timeline.py
```

## Best use cases

- identify recurring activity patterns
- compare workload or topic concentration over time
- collect a quick temporal summary before deeper analysis
- review progress trends across non-Jira datasets as well
